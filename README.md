# Установка перевода сборки Confluence: Journey's Start

В данном небольшом руководстве мы описали инструкции для установки перевода Confluence: Journey's Start двумя способами!

## Важная информация
- Версия Minecraft для сборки 1.20.1
- Загрузчик модов Forge
- Перевод создан для версии сборки 1.2.4-3.12 (вполне вероятно на других версиях он тоже будет работать, но могут возникать ошибки)
- Авторы перевода [BMProjects](https://t.me/BMProjects) (в тг канале можно задавать вопросы по переводу)

## Способ 1 - Установка с нуля:
1. Скачайте архив с полным переводом [Google Drive]()
2. Очистите папку .minecraft
3. Перенесите все папки из архива в .minecraft
4. Запустите игру
5. Приятной игры!

## Способ 2 - Установка в уже имеющуюся сборку:
1. Скачайте архив с только переведёнными элементами [Google Drive]()
2. Перенесите папки config, kubejs, resourcepacks с заменой в папку где находится установленная сборка
3. Запустите игру
4. Приятной игры!

## Скачать оригинальную версию сборки
